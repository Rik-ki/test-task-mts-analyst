# Решение тестового задания: Продуктовый аналитик (МТС Финтех)

**Что это:** Решение реального тестового задания компании МТС для аналитика данных.

**Ссылка на исходное задание:** https://github.com/Hexlet/ru-test-assignments/blob/main/analytics/mts-produktovyj-analitik/README.md

---
## Что сделано и что нет
* **Сделано:** 
  * **Задача 1** анализ результатов A/B-тестирования баннеров, расчёт конверсий и статистическая проверка различий.
  * **Задача 2** SQL-запросы для расчёта расходов клиентов за последние 30 дней и помесячных трат топ-100 клиентов.
* **Не сделано:** 
  * **Задача 3** (Проектирование расчета retention).Не хватило практических и аналитических навыков, а так же ограниченный объём времени. Для её выполнения необходимо дополнительно разобраться в методах расчёта retention.
---
## Как запустить или как читать
* **Для проверки Задачи 1:** Откройте файл `task.py`. Для запуска файла task.py необходим Python 
* **Для проверки Задачи 2:** Откройте файл `task_2.sql`. Файл task_2.sql содержит два SQL-запроса для PostgreSQL. Для их выполнения необходима таблица transact с исходными данными и соответствующими столбцами. Запросы можно открыть и выполнить в PostgreSQL через pgAdmin или другую совместимую среду.
---
## Как проверяли
* Для задачи 1 проверены расчёты конверсий, относительной разницы между вариантами и результат двустороннего z-теста для двух долей.
* Для задачи 2 проверена логика фильтрации транзакций, группировки по клиентам и месяцам, а также выбора топ-100 клиентов.
